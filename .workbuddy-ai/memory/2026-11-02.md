## FloatTrans v1.2.1：有道语言对限制的实测与适配

实测接口 `https://aidemo.youdao.com/trans`（项目在用的免 key demo 接口）：

| 语言对 | errorCode | 说明 |
| --- | --- | --- |
| en->zh、zh->en、zh->ja、zh->fr、zh->ko、Auto->zh(日/法/英原文) | 0 | 正常 |
| en->ja、en->de、en->fr、en->ko、de->fr、ja->ko、ja->en | 102 | 不支持的语言类型 |
| en->zh-CHT、zh-CHT->en | 102 | 繁体也不支持 |

结论：**有道免费接口只支持「简体中文 <-> 其他语言」，不做外外互译，繁体中文也不支持**。
错误码 411 = 访问频率受限（限流，与语言对无关，测的时候要拉开间隔）。
官方付费版 `openapi.youdao.com` 文档的版本记录里有「新增英文与日文互译」，语种表上百种，理论上外外方向更多，但项目拿不到。

代码适配（`float_trans.py`）：
- 新增 `Translator.youdao_supports(src, dst)` 静态方法：`zh-TW` 直接 False，否则要求 `"zh" in (src, dst)`。
- `_chain(engine, src, dst)`：auto 模式不支持时**跳过有道**；手动选有道且不支持时直接抛
  「有道只支持中文与其他语言互译，不支持 英语→日语，请换成 Google 或 MyMemory」，避免白跑一次和看不懂的 102。
- 版本 1.2.1，README 增加「有道只做中外互译」小节 + 实测表，重新打包 exe。

验证：en->ja auto 现在直达 MyMemory（グッドモーリング）；手动有道 en->ja、en->zh-TW 均给出中文提示；
en->zh、zh->en 仍走有道正常。

## FloatTrans macOS 版（用户第二台机器：MacBook Air 13" 2015 / Monterey 12.6.1 / Intel i5 / 4G）

用户要求做 macOS 版。Windows 版依赖全不可移植：ctypes.windll、GDI BitBlt、winsdk Windows.Media.Ocr、
RegisterHotKey、MCI 放音、注册表自启。

架构调整：
- 新增 `trans_core.py`：把翻译核心（UA/http_get/LANGS/ENGINES/lang_code/detect_lang/Result/Translator）
  从 float_trans.py 抽出，Windows 与 macOS 共用。float_trans.py 改为 `from trans_core import ...`，
  只保留 POS_RE/trim_def/UI。**重构后 Windows 版已重测（翻译 + 界面截图）并通过，exe 已重打包。**
- 新增 macOS 平台层：
  * `mac_ocr.py`：`screencapture -x -t png -R x,y,w,h` 截屏 + Vision `VNRecognizeTextRequest`
    （Accurate/Fast 两档，行级 boundingBox 归一化坐标换算成像素，返回 scale 处理 Retina）；
    Quartz 取光标/修饰键/前台 pid；`CGPreflightScreenCaptureAccess` 查屏幕录制权限。
  * `mac_hotkey.py`：Carbon `RegisterEventHotKey` + `InstallEventHandler`（ctypes 直接调 Carbon.framework），
    不需要辅助功能授权；GetEventParameter 取 hotkey id 分派；被占用自动换备用键；pretty_combo 输出 ⌃⌥T。
  * `float_trans_mac.py`：界面照搬 Windows 版（PingFang SC / Menlo），
    RegionSelector 改成「先全屏截图当背景 + 四块 stipple gray25 矩形压暗」而不是 alpha 透明（提示文字不糊）；
    TTS 走 afplay 退回 say；自启写 LaunchAgent；单实例用 fcntl.flock；
    AppKit `setCollectionBehavior_(canJoinAllSpaces|fullScreenAuxiliary|stationary)` 让窗口浮在全屏视频上；
    `--check` 自检输出 Python/tkinter/pyobjc/屏幕录制权限/热键/配置目录。
- 脚本：`start_mac.command`（检查 python3 + tkinter，缺 pyobjc 自动 pip 装）、`check_mac.command`、
  `build_mac.sh`（sips 生成 iconset → iconutil → PyInstaller --windowed）。
- 文档：`README_mac.md`（安装/权限/排错/已知限制/「这些必须在 Mac 上才能验证」清单），
  README.md 增加 macOS 版小节与文件表。

验证（在 Windows 上能做的都做了）：4 个文件 py_compile 通过；`--check` 降级输出正常；

**未验证（必须 Mac 实机）**：Vision OCR 效果与速度、Carbon 热键在 Tk 事件循环下是否派发、
screencapture 坐标与 Retina 缩放（该机 1440x900 非 Retina，scale 应为 1）、无边框窗口键盘焦点。

补充：用户问「macOS 软件不是 .dmg 吗」——`.dmg` 只是分发容器，程序本体是 `.app`。
`build_mac.sh` 升级为 4 步：装依赖 → sips/iconutil 出 icns → PyInstaller --windowed 出 .app
→ codesign ad-hoc 签名 → hdiutil 封 UDZO dmg（内含指向 /Applications 的软链接）。
用法 `./build_mac.sh`（app+dmg）或 `./build_mac.sh app`（只出 app）。
**必须在 Mac 上跑**：PyInstaller 不能跨平台编译、codesign 只有 macOS 有，Windows 侧只能准备脚本。
Gatekeeper 处理：右键→打开；提示「已损坏」用 `xattr -dr com.apple.quarantine /Applications/FloatTrans.app`。
